## ./currently

Building production AI agents for ITC Infotech's internal K-Fabric platform, with focus on modular orchestration, reliable backend services, validation loops, and safer rollout patterns.

- Coding Standards Enforcer Agent: repository analysis, guideline detection, contextual PR feedback
- Build Orchestration Agent: pipeline monitoring, build execution workflows, dependent task triggers
- Dependency Resolver Agent: dependency-file analysis, version conflict detection, fix suggestions
- Reusable orchestration modules: faster agent capability expansion without rewriting core components
